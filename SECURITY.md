# Security and privacy reports

This repository publishes redacted copies of files from a private working setup. If you find a redaction that was missed, or anything else in the repository or its history that looks private (a path on someone's machine, a host name, a client or business name, a person, a credential), please report it privately.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. The report stays private to you and the repository's security advisory participants.

Please do not open a public issue, pull request or discussion about it, and do not quote the private content anywhere public. A public report would publish the very detail it asks to remove.

The same route applies to security problems in the Hugin code.

When a report is confirmed, the content is removed from the repository, and from its history where needed.
